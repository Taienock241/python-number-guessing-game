
# Python Number Guessing Game 🎮

A beginner-friendly command-line game built with Python. The computer randomly selects a number between 1 and 10, and the player tries to guess it.

## Features

- Random number generation
- Interactive user input
- Hints for guesses that are too high or too low
- Tracks the number of attempts
- Congratulates the player when they win

## Requirements

- Python 3

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python number_guessing_game.py
   ```

   On some Windows installations, use `py` instead of `python`.
